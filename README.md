# FastAPI Agent Service Template

## Quick start

- Create a virtual environment and install dependencies: `pip install -r requirements.txt`
- Run the API with uvicorn: `uvicorn app.main:app --reload`
- Open `http://127.0.0.1:8000/docs` to explore the autogenerated OpenAPI schema.

## Project structure

- `app/main.py` — FastAPI application with example order and driver endpoints.
- `app/models.py` — SQLAlchemy models (`Order`, `Driver`, `Vehicle`).
- `app/schemas.py` — Pydantic schemas for request/response validation.
- `app/db.py` — database engine configuration and dependency helpers.

On first launch the app creates an SQLite database (`agent_service.db`) in the project root and seeds a couple of demo drivers with vehicles so the endpoints return meaningful data immediately.
